## 🚀 Featured Project

### 🔐 IPv6 OS Fingerprinting Lab

A practical cybersecurity lab for exploring passive operating-system fingerprinting using IPv6 network traffic and PCAP files.

**Key Features**

- 📡 IPv6 and ICMPv6 packet analysis
- 🔎 Operating-system fingerprint classification
- 📂 PCAP file processing and analysis
- 🐍 Python-based analysis with Scapy
- 📊 Interactive Streamlit dashboard
- 🧪 Synthetic packet captures for controlled testing

**Technologies Used**

`Python` `Scapy` `IPv6` `ICMPv6` `PCAP` `Streamlit`
